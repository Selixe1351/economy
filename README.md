# Economy

A Minecraft Paper economy plugins written in Kotlin, designed for multi-server environments.

## Features

- MongoDB balance persistance
- Asynchronous database operations
- Caffeine balance caching
- Economy API for other plugins
- JUnit 5 unit tests

## Tech Stack

- Kotlin
- Paper API
- MongoDB
- Caffeine
- Gradle
- JUnit 5 / MockK
