# Economy

A Minecraft Paper economy plugin written in Kotlin, designed for multi-server environments.


## Features

- MongoDB balance persistance
- Asynchronous database operations
- Caffeine balance caching
- Economy API for other plugins
- Economy commands with permissions and tab completion
- Offline player balance management
- JUnit 5 unit tests

## Tech Stack

- Kotlin
- Paper API
- MongoDB
- Caffeine
- Gradle
- JUnit 5 / MockK
